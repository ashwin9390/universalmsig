# Testing Guide

How to test universalmsig on every platform — offline, Colab, GitHub CI,
and real vendor hardware.

---

## 1. Offline Tests (any machine, no internet, no GPU, no SDK)

These run everywhere and are the baseline for all CI.

```bash
cd universalmsig
pip install -e .
python tests/test_universalmsig.py -v
```

**Expected output:**
```
test_ane_cpu_routing_in_spec ... ok
test_compile_produces_files  ... ok
...
Ran 51 tests in 0.162s
OK
```

All 51 tests cover:
- ModelSignature format, JSON roundtrip, binary packing
- All 7 offline models × 3 backends = 21 compilation paths
- Dry-run, save/load, hash stability
- Unknown backend rejection
- GQA explicit broadcasting logic layers

1. Go to [colab.research.google.com](https://colab.research.google.com)
2. Upload `universalmsig_demo.ipynb`
3. Runtime → Change runtime type → **T4 GPU** → Save

### Run

| Asset | Works? |

| QNN topology JSON | ✅ Always |

## 3. GitHub Actions — Automated CI

Every push to `main` or `dev` triggers 4 CI jobs:

### test-linux (Ubuntu, Python 3.11 + 3.12)
- Installs package with no vendor SDKs
- Runs all 51 tests
- Tests CLI commands

### test-coreml-linux
- Installs `coremltools`
- Compiles CoreML spec + MIL graph (Linux)
- Verifies `.mlpackage` compilation

### test-macos (macOS-latest, Apple Silicon)
- Installs `coremltools`
- Full CoreML compilation + execution on ANE
- Free Apple Silicon access via GitHub Actions

### test-cli
- Runs all CLI commands:
  ```
  msig-translate --list-models
  msig-translate --dry-run --model Qwen/Qwen2.5-0.5B
  msig-translate --model Qwen/Qwen2.5-0.5B --target all
  msig-translate --model meta-llama/Llama-3.2-1B --target tensorrt
  msig-translate --model deepseek-ai/... --target qnn
  ```

### Push to trigger CI
```bash
git init && git add . && git commit -m "feat: initial release"
git remote add origin https://github.com/YOUR_USERNAME/universalmsig
git push -u origin main
# → Watch CI at: github.com/YOUR_USERNAME/universalmsig/actions
```

## 4. Apple CoreML — macOS (real ANE execution)

### On your Mac
```bash
pip install coremltools
msig-translate --model Qwen/Qwen2.5-0.5B --target coreml --out ./out

# Run the generated MIL graph script
python out/coreml/qwen_qwen2.5_0.5b_mil_graph.py
# → produces qwen_qwen2.5-0.5b.mlpackage

# Load and run inference
import coremltools as ct
import numpy as np
model  = ct.models.MLModel("qwen_qwen2.5-0.5b.mlpackage")
result = model.predict({"input_ids": np.array([[1, 2, 3]], dtype=np.int32)})
print(result)
```

### Via GitHub Actions (no Mac needed)
The `test-macos` job runs on `macos-latest` which includes Apple Silicon M1.
It tests full CoreML compilation + execution on every push — automatically.

## 5. Qualcomm QNN — AI Hub (real Snapdragon hardware, free)

### Step 1: Create free account
- Go to [aihub.qualcomm.com](https://aihub.qualcomm.com)
- Sign up (free developer tier)
- Get your API token from account settings

### Step 2: Install and configure
```bash
pip install qai-hub
export QAI_HUB_API_TOKEN=your_token_here
```

### Step 3: Generate QNN assets
```bash
msig-translate --model Qwen/Qwen2.5-0.5B --target qnn --out ./out
```

### Step 4: Submit to Snapdragon hardware
```python
import qai_hub as hub
import json

# Load the AI Hub job spec generated by universalmsig
spec = json.load(open("out/qnn/qwen_qwen2.5_0.5b_aihub_job.json"))
print("Target devices:", spec["target_devices"])

# For a full submission, export model to ONNX first, then:
# hub.submit_compile_job(model=onnx_model, device=hub.Device("Snapdragon 8 Gen 3"))
# See: https://app.aihub.qualcomm.com/docs/
```

### Available devices (free tier)
- Snapdragon 8 Gen 3
- Snapdragon X Elite
- Snapdragon 8s Gen 3
