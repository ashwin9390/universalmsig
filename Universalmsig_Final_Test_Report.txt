BUG 1 — Layer Allocation Arithmetic Error
  BEFORE: Fast tier = 34 layers (70%)  |  CPU tier = 16 layers (30%)
          34 + 16 = 50 ≠ 24 transformer blocks ← WRONG
          Root cause: npu_layers / cpu_layers counted ALL GPU_FAST objects
          including embed_tokens and lm_head, and reported sub-layers not blocks.

  AFTER:  Fast tier = 17 transformer blocks (71%)
          CPU tier  =  7 transformer blocks (29%)
          17 + 7 = 24 ✅  (= total_layers field)
          Fix: ceil(24 × 0.70) = 17 blocks. embed and lm_head excluded from split.

BUG 2 — GQA Unrolling Missing in CoreML MIL Script
  BEFORE: MIL script passed raw K,V tensors with 2 KV heads directly
          into matmul against Q tensor with 14 heads → shape mismatch crash.

  AFTER:  MIL script generates explicit mb.tile broadcast:
            k = mb.tile(x=k, reps=[1, 7, 1, 1])  # 2 KV → 14 Q heads
            v = mb.tile(x=v, reps=[1, 7, 1, 1])
          Broadcast factor = num_heads / num_kv_heads = 14 / 2 = 7.
          CoreML MIL does not support implicit head dimension broadcasting.

BUG 3 — GQA Unrolling Missing in QNN Topology
  BEFORE: QNN topology passed mismatched Q/KV shapes directly to
          MultiHeadAttention node → HTP runtime error.

  AFTER:  QNN topology inserts explicit Tile broadcast nodes:
            layer_0_k_broadcast: Tile(multiples=[1,1,7,1])
            layer_0_v_broadcast: Tile(multiples=[1,1,7,1])
          48 broadcast nodes total (24 K + 24 V) for Qwen 24-layer model.
          QNN HTP cannot implicitly broadcast mismatched head dimensions.

BUG 4 — Colab Install Failure (pyproject.toml build backend)
  BEFORE: build-backend = "setuptools.backends.legacy:build"
          → BackendUnavailable error on Python 3.12 in Colab

  AFTER:  build-backend = "setuptools.build_meta"
          → Standard stable backend, works on Python 3.11 and 3.12
